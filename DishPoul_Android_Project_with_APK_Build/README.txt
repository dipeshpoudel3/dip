Dish Poul habit tracker - Android project + standalone app
Features: 30 tracker modules, stylish dashboard, login screen, local browser storage, export/import JSON.
Default demo login: Dish Poul / ADMINHOT
IMPORTANT: Demo login is not security. App data uses WebView local storage, which is not encrypted. Do not store real passwords, PINs, sensitive data, or medical information. The Password Vault is only a placeholder tracker and is not suitable for secrets.
Nutrition estimates are manual-entry fields; there is no live food database/API in this prototype. BS calendar date field is manual.
APK not included: Android build tools/SDK are not available in this environment. Build the APK with Android Studio (instructions below).
Build: open project in Android Studio, allow Gradle sync, Build > Build APK(s). The APK is normally under app/build/outputs/apk/debug/app-debug.apk.
